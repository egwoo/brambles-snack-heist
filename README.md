# Bramble's Snack Heist

A cozy stealth game in one HTML file. Bramble, an antlered forest giant, sneaks around a campground stealing snacks while the campers go about their day.

Open `index.html` in a browser to play. Everything (art, music, sound) is drawn or synthesized in code, so there are no other files.

## Controls

- **Move:** WASD / arrow keys, or hold the mouse to steer and click to walk somewhere
- **Tiptoe:** hold Shift, or press C to toggle (silent but slow)
- **Rummage / use:** hold Space or E
- **Toss a pinecone:** right-click or Q
- **Eat from your pouch:** F
- **Journal / map / pause:** J / M / Esc
- **Gamepad and phone:** supported (stick plus on-screen buttons)
